# MyCortex 记忆客户端

客户端以独立 Windows 窗口显示已保存的记忆，直接使用与 MCP 相同的知识库。支持搜索、新增文字/来源链接、查看完整正文和来源、修改正文、历史版本及删除。

## 打开

在项目目录中运行：

```powershell
& .\scripts\mycortex-desktop.ps1 `
  -Store D:\Cache\MyCortex\mcp-demo `
  -BrowserProfile D:\Cache\MyCortex\client\browser
```

需要 Windows、Microsoft Edge、Node.js 24.16+ 和已安装的项目依赖。启动器使用项目源码，移动项目后须更新启动路径；目前不是可独立分发的安装包。

本机启动快捷方式位于 `D:\Apps\MyCortex\MyCortex.lnk`，可双击打开。上述 store 与当前 Codex MCP 试用配置一致；这是试用目录，正式资料目录尚未确定。客户端不扫描其他资料目录，不自动搬迁数据。窗口内“存储位置”可查看实际目录。

## 使用

- 左侧按最近保存时间列出记忆，每页 20 条。搜索匹配标题、正文、来源与已有整理结果；多个关键词用空格隔开，最多 6 个，各不超过 100 字符，显示最近 10 条匹配。
- 选中记忆后，右侧“原文”显示完整正文、原作者、来源时间及保存时间。“整理结果”单独显示已有派生解释与原话引用；界面本身不调用模型。
- “新增记忆”可保存文字或仅保存来源链接。链接不自动抓取正文。未知作者和来源时间保持未知。
- “编辑”修改当前文字记忆的完整正文，创建新版本，保留标题、来源与原作者。可填写修改说明。来源链接没有已保存正文，新增文字记忆可保留相关内容。
- “历史版本”查看最近 50 个修订，历史内容只读。“返回当前版本”回到可编辑版本。
- “删除”在确认后清除本库该条记忆的正文、整理结果及全部历史；不能撤销，不删除原始文件。
- 其他 AI 或客户端修改同一条记忆后，旧编辑/删除会提示版本冲突。编辑草稿保留在弹窗中，可先复制，再取消并刷新当前版本。保存失败时没有自动重试；结果未知时先核对列表与当前版本。
- 其他连接新增/修改后，点击“刷新”读取最新内容。

正文上限沿用现有 256 KiB；客户端会分段读取完整版本，编辑不会只保存预览片段。存取、修订和删除由既有知识库 Worker、事务及进程锁执行。

## 本地服务

每次启动只监听 `127.0.0.1` 随机端口，通过该次启动令牌访问 API，不向局域网开放。使用独立 Edge 数据目录；正文以纯文本呈现，不执行其中的 HTML。窗口关闭并停止心跳后，服务约两分钟退出。后台窗口受系统节流或设备休眠时，连接可能失效，重新打开入口即可。

调试时可打印本地访问地址并使用普通浏览器：

```powershell
node --import ./scripts/tsx.mjs scripts/mycortex-desktop.mts --store D:/Cache/MyCortex/mcp-demo
```

打印的地址包含本次启动凭据，不应分享或写入公开日志。此本地客户端沿用现有明文 SQLite；服务器部署与 E2EE 仍需另行实现。

## 验证

```powershell
node scripts/run-vitest.mjs src/knowledge/desktop-server.test.ts --maxWorkers=1
```

HTTP 集成测试使用隔离合成库与真实 Worker/SQLite，覆盖全文、幂等提交、搜索、修订、冲突、历史、删除及请求边界。独立浏览器验收包含草稿保留、并发刷新时编辑/删除目标固定、长文编辑、取消、来源链接、纯文本显示、重新加载和桌面/窄屏布局。验证不操作用户真实资料。
